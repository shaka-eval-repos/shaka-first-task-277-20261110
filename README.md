# shaka-277-trial

Disposable public fixture for live acceptance checks on
[shakacode/shaka#277](https://github.com/shakacode/shaka/issues/277). Synthetic content only;
safe to delete.

`bin/greet NAME` prints a greeting. Run `bin/setup`, `bin/test`, and `bin/validate`.

Use `bin/greet --plain NAME` to omit the exclamation point. Without a name,
`bin/greet --plain` prints `Hello, world`.
